ยินดีต้อนรับสู่ AdminLTE v4 Starter Kit

สรุปการเปลี่ยนแปลงหลักในเวอร์ชัน 4:
  • Bootstrap 5 Integration: รองรับการใช้งาน CSS / Components ของ Bootstrap 5 เต็มรูปแบบ
  • Vanilla JS: ตัดการใช้ jQuery ออกทั้งหมด เพื่อประสิทธิภาพและความเบาของเว็บ
  • Data Attributes ใหม่: เปลี่ยนจาก data-widget เป็น data-lte-toggle และเปลี่ยน Bootstrap data-toggle เป็น data-bs-toggle
  • CSS Utility Classes: เปลี่ยนจาก ml-* / mr-* / float-left / float-right เป็น ms-* / me-* / float-start / float-end
